# CodeBoard Backend API 🚀

Серверная часть кроссплатформенной образовательной системы **CodeLearn**, предназначенной для интерактивного обучения программированию, проведения автоматизированного тестирования решений студентов и комплексного управления учебным процессом.

Проект представляет собой масштабируемый REST API, разработанный на платформе **Node.js** с использованием веб-фреймворка **Express.js** и объектно-реляционной базы данных **PostgreSQL**.

---

## 🛠 Стек технологий

- **Runtime-среда:** Node.js (LTS 18+ / 20+)
- **Веб-фреймворк:** Express.js
- **База данных:** PostgreSQL (развернута в облачной инфраструктуре Supabase)
- **Аутентификация & Безопасность:** JSON Web Tokens (JWT), Bcrypt / Bcryptjs (хеширование паролей)
- **Удаленная компиляция:** Интеграция с сторонним сервисом компиляции **JDoodle API** через Axios

---

## 🚀 Пошаговое руководство по локальному развертыванию

Для успешного запуска серверного приложения выполните следующие шаги:

### 1. Подготовка окружения
Убедитесь, что на вашем компьютере установлена актуальная версия Node.js. Откройте терминал в корневой папке бэкенд-проекта (там, где находятся файлы `index.js` и `package.json`):

Добавьте в файл .env строки для подключения к JDoodle API

### 2. Установка зависимостей
Выполните установку зависимостей проект, выполнив команду: npm install
Эта команда создаст директорию node_modules и загрузит туда все пакеты, зафиксированные в package.json.

### 3. Подключение к БД
Конфигурация подключения к реляционной базе данных уже интегрирована в файле db.js с помощью пула соединений (pg.Pool). Сервер взаимодействует с удаленной СУБД PostgreSQL на платформе Supabase AWS. При разворачивании собственного экземпляра базы данных скорректируйте строку connectionString внутри db.js.

### 4. Запуск сервера
Для запуска сервера нужно выполнить следующую команду: npm run dev

### 📂 Справочник по API Маршрутам (Эндпоинтам)
Все эндпоинты серверного приложения используют глобальный префикс /api.

### 🔐 Аутентификация и Сессии (/api/auth.routes.js)
POST /register — Регистрация нового аккаунта. При создании пользователю автоматически присваивается базовая роль Ученика (role_id: 1). Пароль проходит безопасное одностороннее шифрование. Возвращает валидный JWT-токен.

POST /login — Аутентификация пользователя по логину и паролю. Сверяет хэши паролей и генерирует JWT-токен со сроком жизни 24 часа.

GET /auth — Защищенный маршрут проверки сессии. Расшифровывает переданный токен в заголовке Authorization: Bearer <token> и возвращает актуальный объект текущего пользователя.

### 👤 Управление пользователями (/api/user.routes.js)
POST /user — Прямое создание пользователя (административный эндпоинт).

GET /user — Получить полный список учетных записей.

GET /user/:id — Загрузить детальную информацию о конкретном пользователе по его идентификатору.

PUT /user — Обновление данных профиля (имя, фамилия, почта, номер телефона).

PUT /changerole/:id — Административное изменение или сброс роли пользователя.

DELETE /user/:id — Полное безвозвратное удаление аккаунта.

### 📚 Управление обучающими курсами (/api/course.routes.js)
GET /courses — Загрузить полный перечень курсов платформы (выполняется сложный SQL-запрос со сборкой данных об авторе и названии языка программирования).

GET /course/:id — Получить информацию об одном конкретном курсе.

POST /course — Создать каркас курса (доступно преподавателям/администраторам с role_id: 2).

PUT /course/:id — Редактировать метаданные курса (название, описание, прайсинг, статус публикации).

DELETE /course/:id — Удалить курс.

GET /courses/creator/:creator_id — Выборка всех авторских курсов конкретного преподавателя.

### 📖 Структура уроков и контент лекций (/api/lesson.routes.js & lessonContent.routes.js)
GET /course/:courseId/lessons — Получить полный список уроков выбранного курса (строгая сортировка по возрастанию порядкового номера order_number).

GET /lesson/:id — Загрузить метаданные урока (заголовок, тип, связь с курсом).

POST /lesson — Добавить новый пустой урок в рамки курса (типы контента: 1 — Текст, 2 — Видео, 3 — Задача).

PUT /lesson/:id — Обновить конфигурацию урока (например, на лету изменить тип урока с текста на задачу).

DELETE /lesson/:id — Удалить урок.

POST /lesson-content — Прикрепить к уроку текстовый материал или прямую ссылку на видеохостинг YouTube.

GET /lesson/:lessonId/content — Загрузить содержательную часть лекции для отображения в интерфейсе плеера или текстового блока.

### 🧩 Практические задачи и Тесты проверки кода (/api/task.routes.js & taskTest.routes.js)
GET /task/lesson/:lessonId — Получить формулировку задачи и стартовый шаблон кода, закрепленные за конкретным уроком.

POST /task — Инициализировать или обновить задачу (условие, начальный шаблон starter_code, эталонное авторское решение, язык программирования).

POST /task-test — Привязать к задаче автоматизированный тест. Принимает входной поток (input_data), ожидаемый консольный вывод (expected_output) и флаг is_hidden (для скрытия кейсов от глаз студентов).

GET /task/:taskId/tests — Загрузить весь пул тестов для администрирования задачи преподавателем.

POST /submit — Основной вычислительный эндпоинт. Принимает код студента, извлекает тесты из базы, поочередно выполняет их в изолированной песочнице через стороннее API компилятора JDoodle, очищает результаты выполнения от лишних спецсимволов (.trim()) и сверяет их с эталоном. Возвращает детальный JSON-отчет о прохождении или ошибках компиляции.

### ❤️ Подписки и Избранное пользователя (/api/favorite.routes.js & subscription.routes.js)
Данные сущности полностью разделены в базе данных на уровне изолированных таблиц favorites и subscriptions.

GET /favorites — Получить одномерный числовой массив ID всех курсов, сохраненных текущим пользователем в персональные закладки.

POST /favorite / DELETE /favorite/:courseId — Взаимодействие с вишлистом (добавление/удаление).

GET /subscriptions — Получить массив ID курсов, на которые пользователь официально записан и проходит обучение.

POST /subscription / DELETE /subscription/:courseId — Оформить подписку на курс или отписаться от него.

### 💾 Схема Базы Данных (DDL Context)
Для понимания связей сущностей ниже представлена структура основных таблиц СУБД PostgreSQL:

users — хранение профилей пользователей (связь с таблицей roles по role_id).

courses — учебные курсы (связи с авторами из users и языками из languages).

lessons — уроки, привязанные к курсам.

lessons_content — текстовый или медийный контент уроков.

tasks — практические задания с хранением условий и шаблонов кода (внешний ключ на lessons).

task_tests — наборы входных и выходных параметров для автоматической проверки решений студентов (внешний ключ на tasks).

favorites / subscriptions — таблицы связи "многие-ко-многим", соединяющие профили пользователей с доступными курсами.
